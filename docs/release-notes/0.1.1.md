## 本版内容

**部署**

- 修复 `tools/start-stack.ps1` —— 补 `$ScpBase` 定义，自定义 `ssh_port` 时 `hidden-run.vbs` 上传不再漏 `-P`，NapCat 隐藏壳任务重建不再挂。
- 调整 `tools/deploy-stack.ps1` —— schtasks 调用按 P30 临时降 `$ErrorActionPreference`，EAP=Stop 下 stderr 不再被包成 `NativeCommandError` 误中断。
- 新增 `host/plugin/qqbotstack_tools/requirements.txt` —— yt-dlp / aiohttp 依赖声明入仓，缺 yt-dlp 时 B 站解析走 OG 兜底而非崩溃。
- 调整 `docs/ARCHITECTURE.md` §5 —— 补「重建 AstrBot / zgate 自启」的 schtasks 命令与 zgate install 口径。

**仓库**

- 调整 `.gitignore` —— 补 `*.env.*`、`*cookie*`、`id_ecdsa*`，挡住 `foo.env.local` / `cookie.json` / `id_ecdsa`。
- 修复 `tools/check-docs.py`、`tools/check-secrets.py`、`tools/build-worldbook.py`、`tools/make_social_preview.py`、`tools/verify-stack.py` —— GBK 控制台结论行改 ASCII，检查全过不再自毁。

需要 Windows 10/11、一个 QQ 号（建议小号）、一个 WorkBuddy 账号。
