**本版只改文档与插件描述：部署脚本、插件代码与运行方式和 0.1.1 完全相同，已经装好的机器不用重装。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/QQBotStack/issues/new/choose) 反馈 —— 请附 Windows 版本、出问题的组件、执行的完整命令与输出原文。

## 本版内容

**门面**

- 新增 仓库里有什么 —— 根 README 列出六支脚本与五个自研插件各自干什么；插件配置用各自的 `config.example.json` 复制成 `config.json`（不入库）。
- 调整 使用步骤 —— 操作机先准备 `host/stack.conf`；NapCat 安装器是交互式控制台程序，要到桌面会话里跑（SSH 里跑不了）；验收是五项自动探测，外加在 QQ 里人工发一条消息确认。
- 调整 运维入口 —— 根 README 补 NapCat 反连配置 `onebot11_<QQ-ID>.json`、`quicklogin.txt` 换号、`stack-menu.cmd` / `get-qr.ps1` / `sync-auths.ps1` 与每日同步任务。
- 调整 第三方声明 —— 鸣谢表补 astrbot_plugin_parser、astrbot_plugin_music、FFmpeg；写明 zgate 由 ModelBus 仓安装，本仓只依赖任务名。

**文档**

- 调整 工具手册目录树 —— `docs/TOOLS.md` 补上五个插件与全部脚本，`docs/` 标注 14 篇。
- 调整 部署参数表 —— 补 `-GatewayExe` / `-NapCatVersion` / `-LauncherVersion` 三个参数；`-WhatIf` 写明是演练模式，下载与写配置都只打印不执行。
- 修复 验收项数 —— 由「五步验收（含端到端问答）」改为「五项自动探测 + 人工确认一条问答」，与脚本实际做的事一致。
- 修复 参数表断行 —— `start-stack.ps1` 的 `-Conf` 参数归回参数表，不再夹在表格与说明之间。
- 调整 网关口径 —— 根 README 与架构文档统一为 AstrBot → zgate `127.0.0.1:7871` → wb2api / OpenCode；`7863` 只是 wb2api 内部端口与探活目标。
- 调整 安全边界 —— 局域网只对 6185 面板开放，且需要先改掉初始密码并限网段；网段写成占位符，不写死具体网段。
- 调整 世界书入口 —— 全本素材来自兄弟仓，本仓没有 `设定/` / `大纲/` 目录；生成脚本与源文件都在本地 `.work/`（不入库，克隆后要自备）。
- 调整 部署设计定位 —— 「zgate 不迁」标为已被现行方案取代的初版结论，并指回架构文档。
- 调整 文档分类表 —— 补齐六篇此前没登记的文档，与磁盘上的文档对齐。
- 修复 跨仓出处 —— 踩坑手册里的仓名由 ZcodeAIModels 改为 ModelBus。

**插件**

- 修复 表情机缘的描述 —— 改为「模型选图为主、随机兜底为辅（兜底默认关闭）」：仓库里的兜底代码默认是关的，只有 `config.example.json` 把它打开；开启后要同时满足五条才会追加一张图。

需要 Windows 10/11、一个 QQ 号（建议小号）、一个 WorkBuddy 账号。
部署脚本会装 QQ 与 AstrBot、建计划任务，执行前请先看 [架构与边界](../ARCHITECTURE.md) 的「会改什么」。
