**首版：把「QQ bot + 协议端 + 模型网关」装成一套，从零到能对话只要一条命令。**

遇到问题、想要新功能，到 [Issues](https://github.com/MVennn/QQBotStack/issues/new/choose) 反馈 —— 请附 Windows 版本、出问题的组件、执行的完整命令与输出原文。

## 本版内容

**部署**

- 新增 `tools/deploy-stack.ps1` —— 分阶段幂等部署，网关阶段不需要人工。
- 新增 `tools/verify-stack.py` —— 五步验收，失败项直接给排错条目号。
- 新增 `tools/start-stack.ps1` / `start-stack.cmd` —— 计划任务起停全套组件，`-Status` 看端口探活、NapCat 登录态与待扫码标记；配套 `stack-menu.cmd` 双击控制台、`get-qr.ps1` 远程拉扫码图（登录态过期不用跑到机器前）。
- 新增 `tools/sync-auths.ps1` —— 账号池「操作机唯一持有 + 目标机消费副本」，每天定时同步并保活。

**插件（AstrBot）**

- 新增 `qqbotstack_guard` —— 唤醒与回复策略：指定群按「@ 机器人 / 包含关键词 / 随机插话」唤醒，其他群一律不回；复读与追问句式抑制、上下文折叠、按话题复杂度混合路由（全免费模型档）。
- 新增 `qqbotstack_worldbook` —— 世界书条目的检索打分与注入块（配 `tools/build-worldbook.py` 生成管线）。
- 新增 `qqbotstack_people` —— 按 QQ 号的两层人档记忆：近期消息缓冲 + LLM 抽取的长期画像与事实表。
- 新增 `qqbotstack_memechance` —— 表情菜单提醒与泄漏清洗。
- 新增 `qqbotstack_tools` —— 分享链接解析、推荐吃饭等对外内容类 LLM 工具。

**文档**

- 新增 部署设计 / 架构与边界 / 排错手册 / 维护手册 / 踩坑手册 —— 从选型取舍、账号安全边界到「哪几步必须亲自做」。

---

需要 Windows 10/11、一个 QQ 号（建议小号）、一个 WorkBuddy 账号。
部署脚本会装 QQ 与 AstrBot、建计划任务，执行前请先看 [架构与边界](../ARCHITECTURE.md) 的「会改什么」。
